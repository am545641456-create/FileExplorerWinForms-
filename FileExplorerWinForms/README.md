# File Explorer – مستكشف الملفات

مشروع **Windows Forms** بلغة **C#** يعمل كمستكشف ملفات مبسط يشبه مستكشف Windows، يسمح باستعراض الأقراص والمجلدات والملفات والتنقل بينها وفتح الملفات.

## المتطلبات المنفذة

1. **إنشاء المشروع**: مشروع `Windows Forms App` باستخدام C# داخل Visual Studio (`.NET 10`, `net10.0-windows`).
2. **تصميم الواجهة**: واجهة احترافية باستخدام `SplitContainer` لتقسيم الشاشة (يسار: الأقراص/المجلدات، يمين: الملفات).
3. **TreeView**: عرض جميع الأقراص في القسم الأيسر، مع عرض المجلدات الفرعية بشكل تفاعلي (تحميل كسول عند التوسيع).
4. **ListView**: عرض الملفات والمجلدات في القسم الأيمن مع 3 أعمدة: `Name`, `Type`, `Size`.
5. **عرض الأقراص والمجلدات**: استخدام `DriveInfo.GetDrives()` للأقراص و`Directory.GetDirectories()`/`DirectoryInfo` للمجلدات والملفات.
6. **التنقل**: ربط `TreeView` مع `ListView`، عند اختيار مجلد يتم عرض محتواه تلقائياً، مع شريط علوي يعرض المسار الحالي.
7. **فتح الملفات**: استخدام حدث `DoubleClick` على `ListView` و`Process.Start()` لفتح الملف بالبرنامج الافتراضي في Windows. النقر المزدوج على مجلد ينتقل إليه.
8. **معالجة الأخطاء والاختبار**: معالجة أخطاء الوصول للمجلدات المحمية/غير المصرح بها، المجلدات المحذوفة، وأخطاء الإدخال/الإخراج عبر `try/catch` مع رسائل واضحة، بدون توقف البرنامج. تم اختبار البناء بنجاح.

## ميزات إضافية

- أيقونات مدمجة للأقراص والمجلدات والملفات (يتم توليدها برمجياً).
- شريط علوي يعرض **المسار الحالي**.
- زر **Refresh** لتحديث العرض الحالي.
- زر **Back** للرجوع للمجلد السابق.
- ألوان مريحة وخط Segoe UI.

## طريقة التشغيل في Visual Studio (خطوة بخطوة)

1. افتح **Visual Studio**.
2. اختر **Open a project or solution**.
3. انتقل إلى المجلد:
   `C:\Users\unknown\Documents\Default Project\FileExplorerWinForms`
4. افتح الملف:
   `FileExplorerWinForms.csproj`
5. انتظر حتى تنتهي عملية Restore/Load للمشروع.
6. تأكد أن التكوين هو `Debug` والمنصة مناسبة (Any CPU).
7. اضغط **F5** أو زر **Start** لتشغيل البرنامج.
8. عند ظهور النافذة:
   - اختر قرصاً/مجلداً من **TreeView** (يسار) لعرض محتواه.
   - انقر نقراً مزدوجاً على ملف في **ListView** (يمين) لفتحه.
   - انقر نقراً مزدوجاً على مجلد للانتقال إليه.
   - استخدم **Back** للرجوع، و**Refresh** للتحديث.
